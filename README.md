# kanban-slack-icons

Kanban's issue-type icons as PNGs, hosted here so Slack can fetch them as the
big icon on Kanban's automation cards (`kanban-<type>.png`, e.g.
`kanban-bug.png`), with a copy of each seated for the line that carries the
issue number (`kanban-<type>-inline.png`), and the status icons a close or a
hold wears as its big icon instead (`kanban-status-<tone>-<glyph>.png`, the
issue page's status chip glyphs).

This is temporary: once Kanban can serve its own images to Slack, it will stop
pointing here and this repo will be archived. The icons are rendered from
Kanban's own type icons; don't edit them by hand.
